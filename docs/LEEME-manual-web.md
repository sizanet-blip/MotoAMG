## 2. Pega el HTML

1. Abre `docs/manual-web-cms.html`
2. Selecciona todo → copia
3. Pégalo en el campo **contenido** del CMS (modo HTML/código)

## 3. Guarda y revisa la web

Comprueba que las URLs tipo  
`https://panel.albertomaestre.es/uploads/cms/01_motoamg_inicio.png`  
cargan bien.
